## この実例から読み取れる規則

1. **左右の1段ずれ**: 右半面 = 左半面の先頭にナミを1段足してずらしたもの（4-13 の対称柄規則と一致）
2. **成長フェーズ**: 菱形が広がる間は「上n」が **2段ずつ同じ値で 1,1,2,2,3,3,…** と増える。ほとんどの段に⬆
3. **戻しは一括**: 菱形の縮小側は段ごとに書かず、**最終段に「②〜⑥ナミ」**（丸数字の範囲 = 入れかえていた糸番号がまとめて元に戻る）
4. **糸番号リスト**: 「2.3.4.5.6 上4⬆」のように、入れかえる糸の番号列 + 目数が併記される段がある（ブロック4の最大幅の段）
5. **下上下4 / 下2上下3**: 大きい菱形で前の模様と連続する部分に現れる（下1上1下4 / 下2上1下3、合計6）
6. **数字は糸番号**（綾書定規の目盛りではない — ユーザー確認済み）

## 手取りの機構（書籍 4-4〜4-8、p.124-128 より）

各半面は上段15本＋下段15本（60玉）。1段の記号は次の3要素からなる：

1. **糸交換（先頭の数字）** — 4-8: 「綾の取り方の前に数字がある場合は、上段と下段の糸を入れかえる。
   手前から1・2・3…と糸を数え、『2・3』なら上下段の2番目どうし・3番目どうしを入れかえる。
   丸の付いた数字は、入れかえると元の色に戻る」。数字＝手前から数えた糸の対の位置。
2. **綾の名前** — ナミ／上1／上2／…／上6。「上n」は「上n下(6-n) と 下n上(6-n)」の対の手取り
   （下腕と上腕で一対）。**60玉の場合、綾の合計は常に6**（4-6 に明記）。
   4-13 の「上1下5」等はこの正式名、4-15 の「上1」等は略記。
3. **⬆** — 手取りの糸が移動先で上段に入る（上ル）段の印（4-4 ナミ⬆の図）。

## 実装状況との対応

- 綾の名前 ＝ 1目おき6目の上下の並び → **実装済み**（現在の 上a下b 出力がそのまま綾名になる）
- 糸交換リスト（数字・丸数字・②〜⑩の範囲圧縮）→ **未実装**。段間の差分（塗りの反転位置）から生成できる見込み。
  ただし 4-15 ブロック1〜3 の成長フェーズは数字なし（綾の手取りだけで境界が1目ずつ進む）なので、
  「綾で賄える漸進変化には数字を書かず、飛びの変化と一括の戻しにだけ書く」規則の確定が必要
- ⬆ → **未実装**。4-15 では操作の最終段などに付かない。正確な条件は要調査
