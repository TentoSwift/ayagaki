## 手取りの基本（1-4〜1-10）

- 二枚高麗組の綾は、すべて**下段の2上げと上段の2下げが一対**となり、そのどちらかの綾を取る。綾の数は下段「2上げ」・上段「2下げ」をそれぞれ1回と数える。**60玉の場合、手取りの合計は 3**（ナミ／上1下2／上2下1／上3／下上下／上下上／下2上1／下1上2）。
- 上1 = 上1下2 と 下1上2 を行う。上2 = 上2下1（上上下と同じ）と 下2上1。上3 = 上3 と 下3。下上下 = 下上下 と 上下上。下2 = 下2上1 と 上2下1。
- **⬆（上がる）**: ⬆ があれば、最初の手取りの後、くぐり糸を反対側の**上段**へ持って行く（上がる）。次の手取りの後は反対側の**下段**へ（下がる）。つねに⬆と⬇の両方を行う。
- **糸交換**: 綾の前に数字があれば上下段の糸を入れ換える。手前から 1・2・3 と数える。「7.8.9」= 7・8・9 番目の糸どうしを入れ換える。**丸数字は入れ換えると元の色に戻る**。（図 A「7.8.9」、B「⑪⑫⑬」= 手前から数えた位置に両矢印）
- **（下下）**: 上下段ともに下色糸が一番向こうにある場合、手取りの後、2回とも下段の糸がくぐり糸になる。ナミ（下下）の例。「下下」の後は必ず「上上」または「トリ」。
- **（上上）**: 上下段ともに下色糸が一番向こうにあり上段が1玉多い場合、2回とも上段の糸がくぐり糸。「下下」の後、または「トリ」の後に「上上」。
- **（トリ）**: 上下段の色が入れ代わっていてかつ上段が1玉多い場合、最後の手取りの時、上段一番向こうの1玉を一緒に取ってきて押さえ、下段1玉を残しそれがくぐり糸となる。ナミ⬆(トリ) の例。
- 1-15 の説明: 端の目まで模様が来る場合「下下・上上・トリ」が必要。(下下) は一番向こうの糸が上下段とも下段の色糸となる場合（図の上では模様が端の目に出てきた段で(下下)、模様がなくなった所で(上上)）。模様が端の目に1個だけ → (下下) の次の段は (上上)。2個以上 → (下下) と (上上) の間は (トリ)。(トリ) は上下の綾を逆に読み、「上がる」場合は上がらず、「上がらない」場合は上がる。

## 綾書定規（1-11）と綾書の作り方（1-13・1-14）

- 定規の頂点を、右半分の綾書を作る場合は中央のジグザグの左角に、左半分は右角に合わせる。1段ずつずらして用いる。
- 組目にあわせて番号 1（中央）〜13 を書く。**通常 2.6.10 の目は入れ換えないので書き込まない**（番号は 1, 3.4.5, 7.8.9, 11.12.13）。
- **右半分は右上がりの目が手取り、左半分は左上がりの目が手取り**。**右半分は左上がりの目が糸の上下段入れ換え**（左半分は右上がりの目）。中央の目は反対側から来る糸の上ル（⬆）にしてもよい。
- 上下段入れ換えの●印: 中央から端に向かって綾目の色を読み取り、灰（柄）になった部分とそれが白に戻った部分に●印。端の目に模様がない場合、灰色上の●の数 = 白色上の●の数。
- 綾書2（1-14）: 右側から作る。定規を1目ずつずらして読む。**白の綾を下、模様部分を上**と読む。右上がりの目が「白白白」→ナミ、「色白白」→上下下（上1下2）。●印を付けた綾で入れかえ部分の数字を書く。入れかえは手取りの綾に隠れている部分で行うので**3段先まで入れかえられる**。上下段の糸が元に戻った場合は数字に丸。左右対称柄は左右の綾書を入れかえた後、右側 1 にナミを入れ以下1段ずつずらす。
