# 糸交換の表（●印・目の色・綾書の記号）

各ブロック・各半面について、段 r ごとに

- `本` … 本の綾書の記号（素の数字＝入れかえ、丸数字＝元に戻す、⬆＝中心の入れかえ）

- `色 w=0,2,4,6` … その段の定規が横切る偶数畝の目の色（1=柄, 0=白, ?=読めず）。つまり目 (w, k=r) の色

- `●` … その段の定規が横切る目のうち ● 印が検出されたもの（w の一覧）

- `他中心` … 反対の半面の中心の目の色（右半面は (0,r)_L、左半面は (0,r+1)_R）。⬆ と対応する

- `予測` … 本ドキュメントの規則（korai_rule.py）が出す記号
